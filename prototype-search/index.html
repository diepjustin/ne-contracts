NU Contracts — full-text search prototype

Searches inside the actual document text (not just vendor/amount/date), for the subset of contracts that are born-digital PDFs.
Prototype, not linked from the live site yet. Covers all 16,467 documents that have extractable text (about 53% of the ~31,000-document corpus — the rest are scanned images that need OCR, not handled here). The search index itself is 527 MB, but nothing downloads it upfront: each search fetches only the small handful of index pages it actually needs, over HTTP range requests, via sql.js-httpvfs.
